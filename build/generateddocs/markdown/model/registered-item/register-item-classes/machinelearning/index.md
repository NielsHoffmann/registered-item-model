
# ML Item Class Profile (Model)

`ogc.model.registered-item.register-item-classes.machinelearning` *v0.2*

A profile of the Geoprocessing Activity Profile describing machine learning training and inference runs, and registrable ML activity types, using the STAC MLM extension's task, framework/accelerator and input/output vocabulary.

[*Status*](http://www.opengis.net/def/status): Under development

## Description

# ML Activity Profile

A profile of the register-item-class for registers of
**machine learning activity types**: kinds of `prov:Activity` that use machine learning.

---

The reason to declare this as an activity profile is that meachine learning activities need to be documented with respect to risk and the assumptions under which the ML model is deployed
